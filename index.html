Auto-Scheduler 自動排班

A personal desktop tool for scheduling rotating shifts on Google Calendar.
個人自用的 Google 日曆輪值排班桌面工具。

What it does 功能

  • Reads the user's own calendar list and events to show existing schedules.
    讀取使用者自己的日曆列表與活動，顯示現有行程。
  • Generates a weekly rotation schedule and shows a preview (dry run) before writing.
    依人員名單產生每週輪值班表，寫入前先模擬預覽。
  • Creates or deletes shift events on the calendar only after the user confirms.
    使用者確認後，才在日曆上新增或刪除排班活動。

Who can use it 使用對象

This is a personal, non-commercial tool used only by its developer. It is not offered as a public service.
本工具為開發者個人自用、非商業用途，不對外提供服務。

Privacy 隱私權

All data stays on the user's own computer. See the Privacy Policy 隱私權政策.
所有資料僅保存在使用者自己的電腦上，詳見隱私權政策。
