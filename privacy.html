Privacy Policy 隱私權政策

Auto-Scheduler · Last updated 最後更新：2026-09-28

1. Overview 概述

Auto-Scheduler is a personal desktop application that runs only on the user's own computer. It has no server and does not collect data for the developer.
Auto-Scheduler 是只在使用者自己電腦上執行的個人桌面程式，沒有伺服器，也不會為開發者蒐集任何資料。

2. Data accessed 存取的資料

With the user's permission (Google Calendar API scope https://www.googleapis.com/auth/calendar), the app:
經使用者授權（Google Calendar API 權限 calendar）後，本程式會：

  • Read the list of the user's calendars and their events. 讀取使用者的日曆列表與活動。
  • Create or delete shift events, only when the user confirms. 僅在使用者確認後，新增或刪除排班活動。

The app does not access any other Google data. 本程式不存取任何其他 Google 資料。

3. Storage 資料儲存

  • The OAuth token is stored locally in token.json on the user's computer. OAuth 憑證僅儲存在使用者電腦上的 token.json。
  • Calendar data is kept in memory only while the app is running and is not saved elsewhere. 日曆資料只在程式執行期間暫存於記憶體，不另外保存。

4. Sharing 資料分享

No data is sold, shared, or transferred to any third party. Data is exchanged only between the user's computer and Google's servers.
不會出售、分享或傳送任何資料給第三方；資料只在使用者電腦與 Google 伺服器之間傳輸。

5. Google API Services User Data Policy

Auto-Scheduler's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
本程式使用 Google API 取得的資料，遵守 Google API 服務使用者資料政策（含限制使用規定）。

6. Revoking access 撤銷授權

Access can be revoked at any time at myaccount.google.com/permissions, and by deleting token.json.
可隨時在 Google 帳戶「第三方存取權」頁面撤銷授權，並刪除 token.json。
